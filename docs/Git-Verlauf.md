# Ursprünglicher Git-Verlauf

Alle 94 Projektdateien entsprechen bytegenau Netzblick 0.4.1 (ursprünglicher Commit `1af7611b56a41f233ead3a9d69e6dd7c00f89190`). Der Import nach GitHub erfolgte über den Browser und die GitHub-Anbindung.

Der ursprüngliche Verlauf von 0.3.0 bis 0.4.1 ist vollständig in `Netzblick-history.bundle` enthalten. Nach dem Herunterladen lässt er sich separat wiederherstellen:

```sh
git clone Netzblick-history.bundle Netzblick-mit-Verlauf
```

Für die weitere Arbeit am aktuellen GitHub-Repository:

```sh
git clone https://github.com/Chaozz2go/Netzblick.git
```

Der bisherige Verlauf liegt als Archiv vor; er ist nicht mit dem neuen GitHub-Commit-Verlauf zusammengeführt.
